# 서울 지리·부동산 역사 해설 주제 후보

"왜 이렇게 됐나"에 답하는 주제만 고릅니다. 투자 조언("지금 사라")은 하지 않습니다.
각 주제의 사실은 대본을 쓸 때 출처로 다시 확인해야 합니다.

| 번호 | 주제 (제목 후보) | 핵심 질문 | 화면 아이디어 |
| --- | --- | --- | --- |
| 001 | 60년 전 강남은 서울이 아니었다? | 논밭이던 강남이 어떻게 부촌이 됐나 | 서울 지도, 한남대교, 경부고속도로 선 (샘플 대본 완성) |
| 002 | 여의도는 원래 비행장이었다 | 모래섬이 어떻게 금융 중심지가 됐나 | 여의도 지도, 연도 카드 |
| 003 | 목동은 왜 학원가가 됐을까 | 신시가지 계획과 학군 | 목동 신시가지 구역 표시 |
| 004 | 잠실은 원래 섬이었다? | 한강 매립으로 사라진 섬 | 옛 물길 선, 잠실 지도 |
| 005 | 서울 지하철 2호선은 왜 순환선일까 | 노선 계획의 이유 | 2호선 원형 노선 그리기 |
| 006 | 분당과 일산은 왜 같은 해에 생겼나 | 1기 신도시 200만 호 계획 | 수도권 지도, 신도시 5곳 표시 |
| 007 | 서울 아파트 이름은 왜 길어졌을까 | 브랜드 아파트의 역사 | 카드 위주 |
| 008 | 청계천은 왜 덮였다가 다시 열렸나 | 복개와 복원 | 청계천 선, 연도 카드 |
| 009 | 용산은 왜 오랫동안 개발이 늦었나 | 미군기지와 철도 부지 | 용산 지도, 기지 구역 |
| 010 | 은마아파트 재건축은 왜 이렇게 오래 걸리나 | 재건축 절차와 갈등 | 대치동 지도, 단계 카드 |
